# Tuno Windows：桌面音乐库与播放

独立的 Windows x64 / WPF 桌面程序。当前横屏预览使用 Windows Desktop Acrylic 作为真实模糊背景，音乐库、播放页、设置与均衡器均已改为左右布局；保留全屏歌词、鼠标/键盘切歌、倍速和 LibVLC 均衡器。详细进度见 [横屏磨砂方案](HORIZONTAL_ACRYLIC_REDESIGN.md)。

## 使用

安装版请双击 `dist/Tuno-Setup-0.1.0-win-x64.exe`。它会安装到当前用户的程序目录，创建开始菜单入口，并可选择创建桌面快捷方式；可从 Windows「已安装的应用」卸载。安装包已包含 .NET 10 Desktop Runtime 和 x64 LibVLC，目标电脑无需另行安装这些运行组件。窗口会使用系统 Desktop Acrylic；系统不支持时退回深色实底。程序和安装包沿用 Tuno 圆角音符图标。

1. 点击「添加音乐」菜单，选择「添加文件夹」递归导入，或选择「添加音频文件」多选导入；重新扫描也在这个菜单内。在已选中的歌单里，按钮会变为「添加到歌单」，导入的音频会直接进入该歌单。
2. 搜索框匹配歌曲、歌手、专辑、文件名；使用搜索框右侧的排序菜单调整顺序。
   左侧的「专辑」「艺术家」「文件夹」与安卓端的浏览入口对应；选择分组后显示其中歌曲，搜索继续作用于当前分组。
3. 双击歌曲或选中后点击「播放选中」。歌曲会立即开始播放并打开播放页；当前筛选、排序结果成为播放队列，后续搜索不改变正在播放的队列。
4. Ctrl / Shift 多选后可收藏或加入目标歌单；进入「歌单」页面后输入名称并点击「创建歌单」。选中歌单后可在标题旁点「改名」或「删除」；删除前会提示确认，仅移除歌单和关联，不删除音频。
5. 「移出歌单」只移除关系，不删除音频。程序不会修改音频标签或原文件。
6. 「重新扫描音乐库」更新已添加的文件夹；未变化文件跳过标签读取。损坏标签显示提示，文件丢失保留索引。
7. 底部「随机」按钮切换随机播放，上一首可回到刚播放的歌曲。旁边的播放模式按钮依次切换「顺序播放」「列表循环」「单曲循环」「播完本曲停止」，与安卓端的四档设置对应。顺序播放走到队列末尾即停止；列表循环从末尾回到开头；单曲循环只在自然播完时重播当前曲，手动点击下一首仍会切歌；播完本曲停止会在当前曲结束时停止。随机播放在顺序模式下遍历一轮即停止，在列表循环下开始下一轮。
8. 点击迷你播放器进入左右分栏播放页：封面、歌曲信息、波形进度、播放控制和下一首预览在左，带时间轴的同步歌词在右。当前句平滑移动到中线；手动滚动后约 4 秒恢复跟随，也可点击「回到当前句」。点击波形可跳转进度；优先使用导入歌词，再找同名 LRC 文件，最后读取音频内嵌歌词。点击歌词预览进入全屏歌词。
9. 播放页点击「播放队列」从右侧展开当前歌曲列表；拖动歌曲行，或选中后点击「上移 / 下移」调整顺序。重排不会中断当前歌曲，新的顺序在正常关闭时保存。双击歌曲、按 Enter，或选中后点击「播放选中」即可切歌。点击「关闭」回到歌词。
10. 播放页左右拖动时当前歌曲和相邻歌曲会跟随移动；拖动距离不足会回弹，超过阈值完成切歌。上一首/下一首按钮使用同一转场。上滑或点「全屏歌词」进入歌词页；按 F 也可进入。← / → 后退或快进 5 秒，↑ / ↓ 以 5 格调节音量，PageUp / PageDown 切换上一首或下一首；原有 Ctrl + ← / → 切歌、空格播放/暂停、Esc 返回上一层仍可使用。搜索框、命名框或滑块获得焦点时方向键保留其控件功能。点击底部倍速按钮打开滑轨，可在 0.25×–3.0× 间以 0.05× 调节；1.0× 位于轨道中点，点击中点标签可恢复正常速度。
11. 左侧「设置」可切换歌曲标题/文件名显示、管理主导航入口和排除文件夹；排除目录立即从列表隐藏，并在后续扫描中跳过。左侧「均衡器」打开独立页面，提供 LibVLC 预设和可调频段；语言设置入口会打开 Windows 系统语言页。

正常关闭后记住播放队列、随机与循环模式、进度和音量；重开不自动发声，点击播放继续。偏好设置保存在 `%LOCALAPPDATA%/Tuno/preferences.json`，数据库在 `%LOCALAPPDATA%/Tuno/library.db`。收藏和歌单即时写入，播放位置在正常关闭时保存。
封面读取音频内嵌图片并缓存（单张上限 4 MiB）；当前不读取旁边的封面图片文件。
扫描在后台执行，每 32 首提交一批，取消时已提交批次保留；文件夹完整扫描后才记为扫描来源。
跳过符号链接/目录联接以防止递归循环。路径忽略大小写去重；不同路径的同一歌曲保留为不同文件。

## 构建

在项目根目录执行：

```powershell
dotnet restore windows/Tuno.PlaybackProbe --configfile windows/NuGet.Config --packages windows/.packages
dotnet build windows/Tuno.PlaybackProbe --no-restore
```

依赖：LibVLCSharp 3.10.1、VideoLAN.LibVLC.Windows 3.0.23.1、Microsoft.Data.Sqlite 10.0.12、TagLibSharp 2.3.0。

制作安装包需要 [Inno Setup 7](https://jrsoftware.org/isdl.php) 的 `ISCC.exe`。在项目根目录执行 `& windows/installer/build-installer.ps1`；若未安装在默认位置，追加 `-IsccPath '完整路径\ISCC.exe'`。脚本会还原依赖、生成干净的 x64 自包含发布目录，再编译 `dist/Tuno-Setup-0.1.0-win-x64.exe`。安装后用户数据仍保存在 `%LOCALAPPDATA%/Tuno`，卸载程序不会删除音乐、歌单数据库或偏好设置。

持有已导入当前用户证书库、带私钥的代码签名证书后，可在构建命令后追加 `-SigningThumbprint '证书指纹'`。脚本会先用 SHA-256 和 RFC 3161 时间戳签名 Tuno 的 EXE/DLL，再打包并签名安装包，最后检查签名和时间戳；不要把私钥或证书密码写进脚本。未传证书指纹时构建结果仍是未签名预览版。

```powershell
# 可在末尾追加真实音频路径；合成测试音在独立目录生成

# 传入两个现有 MP3 路径；只对隔离目录中的副本操作
dotnet windows/Tuno.PlaybackProbe/bin/Debug/net10.0-windows/Tuno.PlaybackProbe.dll --library-test windows/verification "第一首完整路径.mp3" "第二首完整路径.mp3"
# 验证 LRC 解析、旁挂文件、导入覆盖及内嵌歌词回退
dotnet windows/Tuno.PlaybackProbe/bin/Debug/net10.0-windows/Tuno.PlaybackProbe.dll --lyrics-test windows/verification "现有 MP3 完整路径.mp3"
```
