# Tuno Windows 横屏布局与真实磨砂方案

## 目标

- Windows 端继续与 Android 保持同一套页面、功能和操作语义，但按桌面横屏重新编排内容。
- 窗口底层使用能透出桌面与后方窗口的系统级 Desktop Acrylic，接近参考图中的 Windhawk 任务栏材质。
- 封面颜色只作为局部氛围光，不再把整页染成深蓝灰色。

## 布局结构

### 音乐主页

窗口使用三层结构：40 px 自定义标题栏、主体左右分栏、98 px 底部播放器。

- 左栏：宽 248 px；放品牌、全部音乐、歌单、收藏、专辑、艺术家、文件夹、歌单列表，以及设置和均衡器入口。
- 右栏：占剩余空间；顶部只放页面标题、搜索、排序和导入；下面放歌曲卡片列表或专辑/艺术家网格。
- 底部播放器横跨主体宽度；左侧显示封面和歌曲信息，中间显示波形及播放控制，右侧显示音量和播放模式。
- 不恢复旧版 DataGrid。歌曲仍使用带封面的卡片行，但从双列卡片改为更适合鼠标浏览的单列紧凑行。

### 播放页

- 左侧约 40%：大封面、标题、歌手、专辑、波形和主播放控制固定在一个稳定区域。
- 右侧约 60%：同步歌词作为主内容，当前句位于视线中心；队列从最右侧以 360–400 px 抽屉覆盖歌词的一部分。
- 左右拖动切歌只作用于左侧封面与歌曲信息，歌词区域保留垂直滚动，避免手势冲突。
- 下一首预览放在左侧控制区底部，不再占用整页横向空间。

### 设置与均衡器

- 左侧沿用同一导航栏，保持当前位置和返回路径稳定。
- 右侧显示设置内容；均衡器继续是独立页面，频段利用横屏宽度展开。

## 材质层级

1. **窗口底层**：Windows DWM `DWMSBT_TRANSIENTWINDOW`，即 Desktop Acrylic；可看见桌面与后方窗口的模糊结果。
2. **导航栏和底部播放器**：单层低透明冷灰遮罩，约 34–46% 不透明度；避免叠加第二层桌面模糊。
3. **主内容区**：基本透明，只用极浅的明暗分区和 8–12% 白色边线表达层级。
4. **弹出队列、菜单和对话框**：更深的半透明遮罩，保持文字对比度。
5. **封面氛围光**：仅在播放页封面周围使用，强度控制在 8–14%，不改变整页基色。

推荐的暗色参数：

- 窗口兜底色：`#E61A2026`
- 左栏遮罩：`#74242F39`
- 主内容轻遮罩：`#241F2A31`
- 底部播放器：`#8A17212A`
- 普通边线：`#20FFFFFF`
- 悬停层：`#18FFFFFF`
- 选中层：`#2AFFFFFF`
- 主文字：`#F2FFFFFF`
- 次文字：`#A8FFFFFF`

参考图的关键特征是强模糊、低饱和蓝灰遮罩、很弱的顶边高光和较深的系统托盘区域；不是蓝灰渐变本身。

## WPF 实现路线

- 保留当前 WPF、LibVLCSharp、SQLite 和业务层，不为材质效果整体迁移到 WinUI 3。
- 新增一个窗口材质服务，在 `SourceInitialized` 后取得 HWND，并调用 `DwmSetWindowAttribute`：
  - Windows 11 build 22621 及以上使用 `DWMWA_SYSTEMBACKDROP_TYPE = DWMSBT_TRANSIENTWINDOW`。
  - 同时启用沉浸式暗色标题栏和系统圆角。
- 窗口保持 `AllowsTransparency="False"`，避免 WPF 分层窗口带来的性能和 DWM 兼容问题。
- 使用 `WindowChrome` 做无边框视觉与可拖动标题栏，同时保留窗口缩放、贴靠、最大化和系统快捷键。
- 删除根层 `GraphiteBackground` 的不透明绘制，窗口及根 Grid 改为透明；内部面板统一改用低 Alpha 的纯色遮罩。
- 当系统关闭透明效果、远程桌面或 DWM Acrylic 不可用时，自动退回 `#1A2026` 实色背景，确保可读性。

## 分步实施

1. **已完成**：接入 DWM Desktop Acrylic，去掉覆盖磨砂的石墨背景，并加一层低透明冷灰遮罩。真实窗口可看到后方内容被模糊；构建为 0 警告、0 错误，播放、媒体库和歌词回归均通过。
2. **已完成**：主页改为 248 px 左侧导航、右侧音乐内容和横向底部播放器。自定义标题栏保留拖动、最大化与缩放；最大化边界按当前显示器工作区计算，避免播放器被任务栏遮挡。
3. **已完成**：播放页改为左封面与控制、右侧同步歌词；队列从歌词右侧展开，跟手切歌只作用于左侧。
4. **初版完成**：设置与均衡器各有独立横向页面和左侧导航；队列加入滑入动画，页面切换沿用淡入和轻微缩放。弹窗与其余细节仍可继续统一。
5. **部分完成**：真实窗口已检查普通尺寸与最大化、壁纸透色、音乐库、播放页、歌词、队列、设置和均衡器；最小 920 px、透明效果关闭、高 DPI 与浅色壁纸仍待逐项验收。

2026-09-27 细节调整：播放页和全屏歌词改为按当前行中心定位，首尾加入滚动余量；取消矩形选中底色，歌词滚动条采用无方形轨道的细圆角滑块。基础字体与常用按钮放大，重复的播放页选项按钮移除，音乐库导入与重扫收进一个菜单。

## 验收标准

- 移动窗口时，窗口后的壁纸或其他窗口轮廓会实时变化，并经过明显模糊；截图中不能只是固定渐变。
- 内容区不出现多层 Acrylic 相邻造成的接缝或重影。
- 浅色和深色壁纸下正文都清楚，封面主色不会污染整页。
- 920 px 最小宽度仍可操作；1180 px 以上稳定显示完整左右布局。
- 最大化、拖动、窗口贴靠、缩放和任务栏交互保持原生 Windows 行为。
